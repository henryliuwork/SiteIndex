# 开发规划：用户实测反馈（2026-10-29）

> 来源：用户在 v0.1.4 实测 Kingsyard 真实项目后的 9 项反馈。本文件是 A / B / C 三个工作流的任务依据，细节以本文件为准。

## 1. 已确认的决策

| 议题 | 决策 |
|---|---|
| 父子 SKU | **feed 里只有子 SKU，父 SKU 由规则推导**。规则可配置，界面提供预览 |
| SEO 问题 / 收录 | **先只整理现有抓取能检测的问题**，不接入 GSC（GSC 留作后续阶段）。批量"检查全部收录"去掉，改为单页手动打开 Google |
| 关注的分类 | **从抓到的分类里勾选 + 可手动补充**（名称、slug、URL）。只影响界面展示，不影响抓取 |
| 运行页 | 三个痛点：手动执行与定时计划混在一起、看不出当前在跑什么、计划编辑太繁琐。需重做 |
| 新增配置的位置 | 博客识别、父子 SKU 规则、关注的分类都属于**项目设置**（每站不同），不是软件设置 |
| 字体 | Geist（中文回退到微软雅黑 / 苹方），最小字号 12px，字体文件随安装包打包 |
