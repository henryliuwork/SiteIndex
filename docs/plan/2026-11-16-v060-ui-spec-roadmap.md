## 2. 字体规范（硬性）

- 中文：**思源黑体（Source Han Sans SC）**；英文/数字：**Geist**。`--font-sans: "Geist Variable", "Source Han Sans SC", "Microsoft YaHei UI", "PingFang SC", sans-serif`（拉丁字符先匹配 Geist，汉字回落到思源黑体）；等宽 `"Geist Mono Variable"`。
- 思源黑体须**随包打包**（不得依赖系统已装），按 unicode-range 子集化或使用已发布的 OFL 打包版本（如 Noto Sans SC，与思源黑体同一设计），B 在 PR 中记录选型与体积；离线（断网）下必须可用，由 C 验证安装包。
- 字号 token（页面 CSS 只能用 token，**禁止裸 `font-size`**）：

| token | 值 | 用途 |
|---|---|---|
| `--fs-page-title` | 20px | 页面/项目标题 |
| `--fs-section-title` | 14px | 区块、卡片标题 |
| `--fs-sub-title` | 13px | 子区块标题 |
| `--fs-body` | **12px** | 默认正文、表格、按钮、输入框（中英文一致） |
| `--fs-caption` | 11px | 辅助说明 |
| `--fs-micro` | **10px（下限）** | 仅副标题/说明性文字；任何地方不得小于 10px |
| `--fs-kpi` | 24px | 指标数字 |

## 3. 产品管理合并（库存 + 产品）

1. **第一步（先评审后动手）**：D 提交一份"合并矩阵"（`docs/` 下的 PR 描述或文档）：逐项列出原库存页、原产品页的 KPI、筛选、表格列、操作按钮、抽屉内容，标出【重复→合并】【独有→保留并归位】【不再需要→删除并说明】。我评审通过后再实现。
2. 目标形态：**一张表**，默认只显示父 SKU（可切换显示子 SKU），一行同时含：库存状态/持续/30 天在线率/趋势、有货变体 x/y、价格、分类、链接；筛选合并；KPI 合并为一条；趋势与分类在线率在右上角抽屉；行抽屉用页内分段展示"概况 / 变体库存 / 历史"。
3. 导航：**不再出现单独的"库存"**；项目默认落地页为**概览**；旧 `/inventory` 路由重定向到产品管理。
4. 表格遵循 v0.3 §3.6 标准（窗口不滚动、表内滚动、每页 50/100/200/全部）。

## 4. UI/UX 规范 → design tokens（B 负责，强制）

必须覆盖并写入 `tokens.css` + `docs/DESIGN.md`：

- **间距**：4 的倍数阶梯 `--space-1..8`；明确"页面内边距 / 区块间距 / 卡片内边距 / 表单项间距 / 按钮组间距 / 表头到内容"各用哪一档，禁止页面 CSS 出现裸 px 间距（允许 0、1px 边框）。
- **控件**：按钮、输入框、下拉、复选框的统一高度（32，紧凑 28）与同一行垂直居中规则；"输入框 + 按钮"并排的标准组合组件（`InputWithAction`），不得各页手写 flex。
- **Tab**：两种且仅两种——① 项目导航 Tab（路由级，页面之间切换，含待办）；② 页内分段 Tab（同一页内容切换，不改路由）。写明何时用哪种、选中态、溢出处理（窄窗口折叠到"更多"）、不得在页内再嵌第三层。待办属于①。
- **页头/右侧菜单**：沿用 v0.3 §3.4/3.5（≤1 主按钮 + ≤2 次按钮 + 更多），并按本文 §5 补充。
- **颜色、圆角、阴影**：沿用 v0.3 §3.2，不得出现裸色值。
- **强制检查**：`ui:check` 的样式扫描由"告警"改为**失败**（裸 `font-size`、裸色值、裸 px 间距、小于 10px 的字号、未登记的组件类）；并增加"同一页出现两个时间"的启发式告警。PR 模板加入规范勾选项。

## 5. 时间展示规则

- 项目头**只显示一处"最近同步：MM-DD HH:mm"**。页面内**不再重复**同步时间。
- 页面里的"数据日期/数据截至"仅在与项目头不同的数据源（如 GSC 数据截至、feed 生成时间）时出现，且放在对应区块的说明行，使用 `--fs-micro`，文案写清来源（如"GSC 数据截至 11-14"）。
- 统一使用共享 `formatDateTime`，禁止"今天/昨天"相对词；B 出逐页清单，D 去重。

## 6. 文档与约束更新（#7）
