# SiteIndex · 产品需求文档（MVP v1.1）

> 2026-10-22 · 平台：**Windows 为主，兼容 macOS**；本地安装运行的桌面软件，不是在线 SaaS。
> 界面以 `design/demo/` 的 21 个画板为准（在线版见 design/README.md）。本文写"做什么、做到什么程度"；"怎么做"见 ARCHITECTURE.md；数据格式见 DATA_SPEC.md。

## 1. 产品定位

> 2026-10-27 起：软件不再管理工作区文件夹，聚焦网站数据索引，见 `docs/decisions/2026-10-27-data-index-focus.md`。

把每个独立站变成一个**标准化的本地项目工作区**（云盘同步的文件夹），供运营人员和各类 agent（Claude Code、Codex、qwenpaw、Qoder…）共同使用。

- **软件负责数据与流程**：新建项目、抓取同步（GMC feed + sitemap）、库存对比、SEO 检查、数据校验、README 维护、定时执行。全部确定性逻辑，**不调用大模型**。
- **agent 负责内容与判断**：写 EDM、博客、外链、页面。agent 读取项目根目录 README.md 即可了解全貌，按 `_agent/skills/` 的说明工作。

## 2. 目标与非目标

**MVP 目标**
1. 输入网址 + GMC feed 地址，3 分钟内生成工作区并完成首次同步
2. 库存、产品、SEO、内容、EDM 首图等日常查看全部在软件内完成，不需要打开数据文件
3. 定时任务在软件关闭时也能执行（Windows 任务计划程序 / macOS launchd），错过可补跑
4. 数据文件损坏或缺失能被发现，并能一键重新生成或修复
5. 任何 agent 只读 README.md 就能开始工作

**非目标（MVP 不做）**
- 不调用大模型；不在软件内写 EDM、博客
- 不接入 Mailchimp 报告、Google Search Console、网站后台销量（界面只预留位置）
- 不做账号体系、云端服务、多人协作
- 不支持 Linux

## 3. 核心概念

| 概念 | 说明 |
|---|---|
| 项目 | 一个网站 = 一个文件夹，位于项目根目录（云盘目录）下 |
| index/ | 项目内的网站数据目录，由软件维护（台账除外） |
| 工作文件 | 用户自己在项目文件夹下建目录归档工作成果；软件不创建、不管理（2026-10-27 决策） |
| Skill | 告诉 agent 某个场景要读哪些数据、怎么查、怎么写台账；不规定成果存放位置 |
| 台账（ledger） | agent / 用户写入的数据：手动首图、标签、关键词映射、EDM 记录、外链去重 |
| 任务（Job） | daily / weekly / monthly / validate / readme / design / index-check |
| 执行设备 | 每个项目指定一台电脑执行定时任务，防止多台设备同时写云盘 |
| 数据校验 | 逐个检查数据文件能否解析、字段、主键、排序、冲突副本；结果写 `index/logs/validation.json` |

## 4. 全局界面规范

| 项 | 要求 |
|---|---|
| 窗口 | 圆角窗口（Windows 11 原生圆角；macOS 原生）；自定义标题栏显示 "SiteIndex"，保留系统最小化/最大化/关闭 |
| 布局 | 左侧导航（项目中心、Skill 中心、定时任务、设置 + 项目列表）；右侧内容；项目页顶部为标签栏 |
| 表格 | **固定最大高度，超出在表格内滚动，表头吸顶**；所有数据表右上角有"列设置"，可勾选显示/隐藏列（记住选择） |
| 详情面板 | 表格行**点击后**在右侧弹出详情面板，可关闭；未选中时表格占满宽度 |
| 筛选按钮 | 高 30px、圆角 6px；选中为主色填充 |
| 大数据量 | 列表超过 200 行时分页（默认每页 20 / 50 / 100 可选）+ 搜索 + 筛选；渲染用虚拟滚动或分页，1 万行不卡顿 |
| 预留字段 | 未接入的数据（销量、GSC、Mailchimp 报告）以灰色表头列 / 虚线卡片显示"预留 · 待接入" |
| 颜色 | 主色 #1E6B52；成功/警告/错误/中性四种状态色；详见 docs/DESIGN.md |

## 5. 页面需求（对应 design/demo 画板编号）

### 5.1 项目中心（1）
- 项目卡片：名称、域名、平台、同步状态、SKU/产品、在线率、博客数、今日变化、执行设备
- 异常卡片高亮（同步失败、超 36 小时未同步、数据校验有错误、feed 未配置）
- 顶部：项目根目录、新建项目、添加已有项目；汇总条（项目数、待处理提醒、今日新缺货、下一个定时任务）；最近运行列表

### 5.2 新建项目向导（2–5，共 4 步）
1. **网址**：检测跳转、robots.txt、sitemap（展开索引）、平台（Magento / WordPress / WooCommerce / Shopify）、语言币种；GMC feed 未公开时提示手动填写
2. **数据源**：填写 feed（可多个）→ 检测：条目数、可用 SKU、产品数、跳过原因、字段覆盖率、主分类分布、示例数据；设置 SKU 字段、主分类层级、商品消失处理方式
3. **品牌配置**：品牌名、市场、定位、人群、文案调性、卖点（自动从首页 / About 提取，可改）；项目位置（根目录 + 文件夹名 → 完整路径预览）
4. **完成**：逐步显示进度（建目录 → 配置 → README → skills → 首次每日同步 → 首次每周同步 → 视图与校验 → 注册定时任务），完成后可打开项目

### 5.3 项目 · 概览（6）
指标卡（SKU/产品、在线率、SEO 问题、博客/关键词、EDM 首图覆盖、30 天销量预留）可点击跳转；"需要关注"列表（数据校验错误、SEO 高危、新缺货、unknown 库存、缺首图）；README 项目概况与当前重点；快捷操作（复制 agent 接入指令、校验本地数据、打开 README、打开项目文件夹）；变更记录

### 5.4 项目 · 库存（7）—— 常用页
- 指标：当前在线率、30 天平均在线率、今日变化、长期缺货（≥14 天）、状态波动（30 天 ≥3 次）
- 分类在线率趋势图（30 天，Y 轴 0–100% 刻度，图例）+ 分类在线率条 + 分类来源说明与"管理分类"入口 + 今日变化
- **SKU 库存明细表**：SKU、产品/变体、分类、价格、当前状态、持续天数、30 天在线率、近 30 天每日状态色块、最近变化；搜索（SKU/标题/变体）、状态筛选（含"今日有变化"）、分类筛选、按在线率排序、列设置
- 导出 CSV、查看今日日报、立即同步

### 5.5 项目 · 产品（8）
- 产品表：产品（含新品/到货/降价角标）、分类、价格（划线价）、有货变体、库存、标签、评分、30 天销量/销售额（预留）；库存与标签筛选；列设置
- 点击产品弹出详情：1:1 主图、价格、库存、评分；**标签可删除、从已有标签添加、新建**；SEO（Title、Robots、Schema 胶囊）；EDM（首图来源、最近推荐）；销售（预留）
- **标签管理**弹窗：所有标签及使用数量、按标签筛选、删除标签（从所有产品移除）、新建标签

### 5.6 项目 · SEO（9）
- 指标：已抓取页面、可索引、**收录（Google site: 检查）**、问题数（高/中/低）、Schema 覆盖、孤立页面
- 三个视图：问题（按级别筛选）、页面（按类型筛选，列设置，含 T/D 长度与收录列）、内链
- 点击弹出详情：Index（已收录/未收录/未检查 + 检查日期）、Title / Description（字符数按红橙绿标色：Title 30–60 绿，20–29 / 61–70 橙，其余红；Description 120–160 绿，70–119 / 161–180 橙，其余红）、Keywords、H1、Canonical、Meta robots、X-Robots-Tag、hreflang、Open Graph、Schema 胶囊、字数/图片 alt、内链出/入、Sitemap（是/否）
- 按钮：打开页面、**检查收录**（打开 `https://www.google.com/search?q=site:<url>`）、检查全部收录（后台低频逐个查询，见架构文档）

### 5.7 项目 · 内容（10）
博客文章 / 关键词映射 / 草稿 三个视图；搜索、筛选（博客：无站内链接、缺 schema、链接缺货产品；关键词：主词、次词、已上线、计划）、分页；指标（博客数、缺 schema、无站内链接、链接缺货产品、关键词数、核心词未覆盖）；展现/点击、排名/搜索量为预留列

### 5.8 项目 · EDM（11）
- 指标：SKU 数、有抓取首图、有手动首图、缺图
- **SKU 宣传图表**：SKU、产品/变体、库存、抓取到的首图 URL（缩略图）、手动输入的首图 URL（可编辑 + 保存，写入 `ledgers/sku_media.csv`）、agent 使用（抓取首图 / 手动首图 / 缺图）；搜索、筛选（有货、未抓取到首图、已填手动图、缺图）
- **取图规则**：agent 默认用抓取首图；抓取不到时用手动首图；两者都没有则该 SKU 不进入 EDM
- "复制 edm-builder 指令"：展开面板，可填主题、数量、折扣码，生成可粘贴给 agent 的指令并复制

### 5.9 项目 · 设计规范（12）
颜色（语义色 + 使用频率色带，**点击色块复制色值**）、字体与字号阶梯、按钮/输入框、间距/圆角/阴影、6 张页面截图；重新提取、打开 tokens.json、复制 page-design 指令

### 5.10 项目 · README（13）
左侧编辑用户区块（项目概况、当前重点、工作规则与偏好）；右侧自动区块列表（只读）；刷新自动区块

### 5.11 项目设置（14、15、17，三个子页；原 16 文件夹页已取消）
- **配置**：基本信息、品牌、数据源（feed、SKU 字段、分类层级、消失处理、保护阈值、feed 生成时间、overrides）、抓取、SEO（核心词、竞品、长度范围、忽略规则）、EDM（平台、每封产品数、冷却期、UTM、图片优先级）、集成与预留数据源
- **分类**：识别方式三选一——URL 规则（Shopify `/collections/`、WooCommerce `/product-category/`）、feed 分类字段、手动配置（Magento 推荐）；手动分类表（名称、slug、分类页 URL、匹配规则：product_type 包含 / SKU 前缀 / URL 关键词 / 指定 SKU，按顺序匹配）、匹配 SKU 数、未归类数；从 sitemap 发现候选分类页一键加入；保存并重新归类
- **本地文件**：按类别列出 index/ 全部数据文件 + README + skills；路径、类型、记录数、大小、修改时间、状态（正常/错误/缺失/冲突副本）+ 原因；每行"校验"；"一键校验全部"；出错时显示修复按钮：自动生成的文件 → 重新生成（执行对应 Job 的局部步骤）；台账 → 自动修复（排序/格式）或从归档恢复；冲突副本 → 删除副本

### 5.12 运行与定时任务（18）
- 手动执行：每日同步、每周同步、每月同步、提取设计规范、刷新 README、数据校验；实时日志与进度、停止
- 运行历史（含执行设备、跳过记录）
- 执行设备卡片（本机 / 其他设备，可"改为本机"）
- **定时计划可编辑**：每个任务启用开关、选择周几（一至日多选）与时间；每月任务选几号；下方选项：到点唤醒电脑、错过后补跑、失败通知、同步后自动校验；保存后更新系统计划任务

### 5.13 Skill 中心（19）
skill 列表（版本、有更新提示）、选中查看读写范围与正文、复制全文/安装说明；安装位置：项目 `_agent/skills`、Claude Code、Codex、自定义目录（如 qwenpaw）；同步到所有项目

### 5.14 软件设置（20）
项目根目录、设备名、本机缓存目录；浏览器检测（Edge / Chrome）与测试；安装命令行到 PATH；通知（系统通知、钉钉 Webhook）；agent 平台 skill 目录；版本、检查更新、日志目录

## 6. 后台任务

| Job | 默认计划 | 内容 |
|---|---|---|
| daily | 每天 02:00 | feed → SKU / 库存 / 事件 / 汇总 / 日报 → 视图（products、sku_stock） → 校验写入文件 |
| validate | 每天 02:30 | 全部数据文件校验 → validation.json |
| weekly | 周一 03:00 | sitemap → SEO 页面 / 问题 / 内链 / 博客 / 分类页 / 产品页详情 |
| readme | 周日 05:00 | 刷新 README 自动区块 |
| monthly | 每月 1 日 04:00 | 站点概况、设计规范、归档 |
| index-check | 手动 / 每周（可选） | Google site: 收录检查（低频） |

计划均可在运行页修改（周几、时间、启用）。

## 7. 非功能需求

| 项 | 要求 |
|---|---|
| 安装 | Windows：NSIS 安装包，按用户安装、无需管理员；macOS：dmg（arm64 + x64）。初期不签名，README 说明首次打开方式 |
| 性能 | 1 万 SKU 的 daily（不含下载）< 30 秒；任何界面操作 < 200ms 响应；后台任务不阻塞界面 |
| 可靠性 | 原子写；保护阈值；同步中断不留半截文件；每次同步后校验写入的文件 |
| 云盘 | 数据库只放本机缓存目录；冲突副本检测；文件占用重试 |
| 编码 | UTF-8 无 BOM、LF；支持中文文件夹名与路径 |
| 安全 | 渲染进程隔离；只访问项目目录、配置的网站与 feed；不保存网站后台凭据 |

## 8. MVP 验收场景（端到端）

在一台干净的 Windows 11 电脑上：
1. 安装 SiteIndex，首次启动设置项目根目录
2. 新建 Kingsyard 项目（真实网址 + GMC feed），完成向导
3. 库存页可搜索、筛选、排序全部 SKU；产品页可编辑标签；SEO 页能看到问题并检查收录；EDM 页手动补一个首图并保存
4. 在 设置 › 分类 用手动配置定义分类，保存后库存页分类在线率更新
5. 在 Skill 中心把 edm-builder 安装到 Claude Code，skill 说明中的数据路径与查询命令可直接执行
6. 人为损坏 `index/seo/links.jsonl`，本地文件页校验报错，点"重新生成"后恢复正常
7. 在运行页把每日同步改为工作日 02:00，关闭软件，等待任务执行成功
8. 用 Claude Code 打开项目文件夹，按 README 完成一封 EDM

## 9. MVP 之后（P2）
MCP 接口（agent 直接查询）、钉钉通知、自动更新、Search Console / Mailchimp 报告 / 销量数据接入、多项目总览、促销活动台账。
