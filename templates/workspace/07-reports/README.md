# 07-reports · 原始报表收件箱

放从分析工具、广告平台或邮件平台下载的**原始数据报表**，供 agent 阅读分析。根目录平铺，不建子目录。

## 命名规范
下载的文件保持平台原始文件名直接放入——这表示「未处理」。
agent 读取并使用后，必须改名为：

`YYYY-MM-DD_<来源>_<范围>_<时间段>.<扩展名>`

- 日期：下载或导出当天
- 来源：使用小写英文标识
- 范围：例如 `queries` / `pages` / `campaigns` / `products`
- 时间段：`YYYY-MM` 或 `YYYY-MM-DD..YYYY-MM-DD`

## 规则
- 不覆盖、不删除原始数据；改名后文件内容保持不变。
- 分析结论写到对应板块，不要写回这里。
- 需要核对口径时，在结论里写明文件名与时间段。
